## 学习板引脚映射（来自 KEYSKING 学习板原理图）

- 循迹 TCRT5000: PB14
- 继电器 SRD-05VDC: PB5（经 SS8050 驱动）
- 超声波 HC-SR04: TRIG=PA10, ECHO=PA11

- 无源蜂鸣器: PB9（**必须 PWM，直接高电平不响**）
- WS2812C 灯带(11颗): PB4（**5V耐受，须开漏输出**）

## 易错点备忘
- AHT20: 上电等40ms；校准位 Bit[3]==1；未校准则发 0xBE,0x08,0x00；测量发 0xAC,0x33,0x00；等75ms 再读6字节(发0x71)；RH=raw/2^20*100, T=raw/2^20*200-50
- AHT20 手册要求每2s测一次，激活时间<10% 避免自热
- I2C1 三器件地址不冲突，但需外部上拉（4.7K）并开 AF_OD
- PB4/PB15/PB13 注意开漏/内部上拉

## CH1116 关键结论（用于 OLED 驱动）
- 控制器 132×64（SH1106 兼容），非 SSD1306。
- 7 位从机地址 0x3C/0x3D（SA0 决定）；**HAL 传 8 位形式 0x7A**（板载丝印 0x7A → 7 位 0x3D）。
- 显存 132 列，**128 面板列偏移 2**（写页列起始 0x02）。
- DC-DC 开：`0xAD,0x8B`（SH1106 风格，不是 SSD1306 的 0x8D,0x14）。
- 控制字节：0x00=命令，0x40=数据。

## OLED 地址三处出处（用户追问后核实）
1. 学习板电路原理图 **第5页** 标注框原文：`I²C address 0x7A` / `Driver CH1116`。
2. CH1116 驱动手册：`Two 7-bit slave addresses (0111100 and 0111101) are reserved for the CH1116. The LSB of the slave address is set by connecting SA0 to VSS(0) or VDD1(1)`。→ 0x3C / 0x3D。
3. **OLED规格书(ZJY130-2864KSWLG01, 中景园)**：`The I2C slave address is 0111100b'. If the customer ties D/C# (pin 15) to VDD, the I2C slave address will be 0111101b'.` → 默认 0x3C，D/C#接VDD 则 0x3D。**并明确写 "Refer to the Technical Manual for the SH1106" → CH1116 确为 SH1106 兼容。**

## 重要更正/确认
- 地址存在分歧：原理图标 0x7A(7位0x3D)，OLED规格书默认 0x3C。**必须以扫描结果为准**。
- OLED规格书自带官方参考初始化 C 代码，其中 `write_i(0x02)/write_i(0x10)` 直接确认了 **列偏移 = 2**。
- 规格书示例 charge pump：`0xAD,0x8A`(外供VCC) + `0x32`(VPP 8V)；板载有 C28/C29 charge-pump 电容 → 用内部DC-DC 应 `0xAD,0x8B`。
- 规格书示例其余：0x81,0xBF(对比度) / 0xA1 / 0xA6 / 0xA8,0x3F / 0xC8 / 0xD3,0x00 / 0xD5,0x80 / 0xD9,0x22。

## CH1116 官方初始化序列（规格书第22-23页 外部VCC / 第26-27页 内部电荷泵 两套）
两套仅4处不同：
- `0xAD` 参数：外部 `0x8A` / **内部 `0x8B`**（板载有 C28/C29 电荷泵电容 → 用 0x8B）
- `0x32`(VPP 8V, 外部) / **`0x33`(VPP 9V, 内部)**
- 对比度 `0x81`+：外部 `0xBF` / **内部 `0xFF`**
- 预充电 `0xD9`+：外部 `0x22` / **内部 `0x1F`**
公共基础序列：0xAE → 0x02/0x10(列偏移2) → 0x40 → 0xB0 → 0x81,xx → 0xA1 → 0xA6 → 0xA8,0x3F → 0xAD,xx → 0x3x → 0xC8 → 0xD3,0x00 → 0xD5,0x80 → 0xD9,xx → 0xDA,0x12 → 0xDB,0x40 → 0xAF
上电要求：RES 拉低→高 后 delay 100ms（规格书标注 "100ms Delay Recommended"）。

4. **oled.h 第12行 `static void OLED_WriteCmd(uint8_t cmd);` 放头文件是错的**（静态函数不该进头文件）。
5. **oled.h 无 `#include <stdint.h>`**：单独 include 报 `unknown type name 'uint8_t'`（已实测）。
6. **编译告警**：`'OLED_WriteCmd' defined but not used [-Wunused-function]`（已实测）。
7. **Core/utils 未加入 include 路径**：root CMakeLists 的 target_include_directories 为空，main.c 里 include "oled.h" 会找不到。
建议：I2C1 加 mutex；底层函数检查 HAL 返回值；地址先扫描确认。
